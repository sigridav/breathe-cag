## Summary

This project examines whether loss of lung function is associated with change in bone mineral density. It is a medical student thesis project (NTNU) linked to the osteoporosis project in HUNT.

## Contents

- `protocol/` – research protocol.
- `rek/` – application, decision letter and amendments.
- `analysis-plans/` – analysis plans per sub-study, written before the analyses start.
- `scripts/` – analysis code.
