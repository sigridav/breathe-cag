## Summary

Little is known about how to support optimal lung function development and how loss of lung function can be slowed. Lung function from adolescence to adulthood is modelled from Young-HUNT and HUNT using Bayesian trajectory analysis. The trajectories are then related to radiological phenotypes in adulthood, such as airway geometry and the size relationship between airways and lung tissue, measured by chest CT. Selected participants are invited for CT, lung function testing and biological sampling, which serve as study endpoints.
